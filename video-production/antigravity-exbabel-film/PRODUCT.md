# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
delegated: static HTML/CSS/GSAP/Anime.js generated via Python script to satisfy Hyperframes requirements.

## Users
Pastors, church audiovisual teams, and congregations containing non-native English speakers (e.g., Spanish speakers).

## Product Purpose
Exbabel provides real-time, low-latency translation for live church services so that multilingual attendees can understand the sermon directly on their own mobile devices without needing a separate service.

## Positioning
"One congregation. Understood." It enables churches to bring multilingual services to their congregation instantly using just a QR code and their phones, without specialized translation hardware or interpreters.

## Operating Context
- Broadcasters (Pastors/AV) use a desktop dashboard.
- Listeners (Congregation) use their personal smartphones.
- In-person live service environment.

## Capabilities and Constraints
- High-fidelity product UI mockups exist as static HTML files.
- The UI contains mobile listener views and desktop dashboard views.
- Must render cleanly as a headless browser capture at up to 2.5x camera scale.

## Brand Commitments
- Deep indigos, stark white grounds, crisp vector shadows (High-contrast SaaS aesthetic).
- Crisp UI interactions, premium presentation.

## Evidence on Hand
- Exbabel logo assets (`exbabel-mark.svg`).
- Storyboard JSON with voiceover script and timings.

## Product Principles
- Erase language barriers seamlessly.
- Zero friction for the listener (no app download required).
- High-quality, premium technical infrastructure.

## Accessibility & Inclusion
- Directly serves non-native language speakers to include them in the primary community event.
