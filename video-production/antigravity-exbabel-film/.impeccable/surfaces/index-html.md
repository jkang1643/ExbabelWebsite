# Surface: index.html

## Scope and Visitor Mode
Persuade/Operate hybrid. High-impact video composition for a product demo.

## Audience, Job, and Context
Pastors and church AV teams looking for a real-time translation solution. The job is to understand how Exbabel works through a seamless, premium visual demonstration.

## Direction Contract
THESIS: A continuous cinematic camera sequence that punches into sharp, focused UI states to dramatize the real-time translation mechanism.
OWN-WORLD: Deep indigos, stark white backgrounds (#FCFCFD), crisp vector shadows, Sora/Inter typography, and clean line art. High-contrast SaaS.
STORY: "One congregation. Understood." We show the problem (fragmented listening), the solution (QR code to live stream), and the outcome (captions on mobile).
FIRST VIEWPORT: A stark white void. Text characters animate in (Anime.js) before the camera aggressively pushes into the first UI panel at 2.2x scale.
FORM: Product-focus-camera orchestration (STATIC -> MOVE -> HOLD -> ACTION -> RESET). Every element arrives via Anime.js character/stagger animations.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
