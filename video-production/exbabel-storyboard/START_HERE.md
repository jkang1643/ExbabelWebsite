# Exbabel storyboard resources

Open [the review page](http://localhost:8768/storyboard.html) while the local server is running.

This package contains a **22-scene, 151-second storyboard**, a reference-motion analysis, a portable skill, and a working anime.js/HyperFrames schematic composition. It preserves the supplied 325-word script, including [First Name] and [Church Name].

## Files

- storyboard.html — scene navigation, scrubbing, static review, narration and production beats.
- storyboard.json — source of truth for scene timing, copy, layouts, layers, beats, transitions, assets and proposed carousel edit.
- storyboard.schema.json — validated JSON Schema.
- MASTER_VIDEO_PRODUCTION_BLUEPRINT.md — all fourteen requested production sections, including scene wireframes, HF specifications and final assembly.
- REFERENCE_ANALYSIS.md — 29 reference states, Video DNA, motion/transition analysis, creative fingerprint and exclusions.
- HIGGSFIELD_PROMPTS.md — three optional single-shot prompts; no generations were run.
- script-verbatim.txt — supplied narration split into production scenes.
- skill/SKILL.md — complete reusable reference-motion-storyboard skill.
- index.html — sole HyperFrames root composition; generated by the build script.
- composition.js / composition.css — schematic animation and styling.
- index.motion.json — HyperFrames motion assertions.
- review-frames/ and snapshots/ — browser proof frames and actual HyperFrames snapshots.
- VALIDATION.md — completed checks and remaining production work.

## Edit and preview in WSL Ubuntu

From this folder:

```bash
npm ci --ignore-scripts
python3 scripts/build.py
python3 -m http.server 8768 --bind 127.0.0.1
```

Then open http://localhost:8768/storyboard.html. The server is currently running for this review. Animation starts paused.

Edit storyboard.json first and rebuild. Timing is in integer milliseconds; HTML attributes are emitted in seconds. The preview consumes scene timing, copy, labels and layout selection. Detailed layer boxes, camera/beat instructions and transition specifications guide final production; the schematic animator demonstrates a common entrance/hold/exit pattern rather than implementing every planned effect.

script-verbatim.txt is a preserved script receipt; don't regenerate it to conceal a narration change. scripts/enrich.py was a one-time authoring helper and is **not** the normal rebuild command. Use scripts/build.py after edits.

Keep [First Name] and [Church Name] until ready to personalize. Actual recorded narration should determine final timing. The 30-second carousel variant is in JSON as an optional 4:3 derivative; its final re-layout has not been built.

## Verify

With the preview server running:

```bash
npm test
npm run check:hyperframes
```

The browser test currently uses the existing local Chromium cache under the user's WSL home; adapt its executablePath on another machine. HyperFrames and anime.js are pinned in package-lock.json. No production site dependencies were changed.

Font files are local. The small Korean font is subset to the current Korean label; the full licensed NotoSansKR.ttf is also supplied for expanding language content. Sora, Noto and anime.js license files are in assets/.

## Reusable skill

A portable copy is in skill/. It has also been installed in the desktop Codex skill directory as reference-motion-storyboard. In a subsequent task, use:

“Use $reference-motion-storyboard to analyze this reference and adapt it to this script. Produce the blueprint, JSON storyboard and HTML review page.”

The skill may need a new task/session to appear in automatic discovery. The local skill path can always be supplied explicitly.

## Scope

This is a finished **preproduction resource package**, not a finished video. Human plates, exact product UI, a real QR, narration and final audio remain production assets. The preview clearly labels placeholders.

The reference was reviewed across its full temporal span using sampled frames and dense transition strips. Its audio was measured but not reliably auditioned. Its original ending is not captured. Those limitations are preserved in the analysis rather than filled with invented findings.

The downloadable ZIP excludes node_modules, the original recording, and extracted reference audio. It includes relevant contact sheets and metadata. Reinstall dependencies with npm ci if rebuilding on another machine.
